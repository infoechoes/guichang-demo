# 贵昌统一 Demo 本地集成代码

沿用现有统一工作台及账号服务；录单原行、参考查价、已确认底稿映射、税率复用和三方报价在原入口接续。

## 启动

1. 使用 Python 3.11+ 安装 `pip install -r requirements.txt`；Node 22.18+，在 `quote` 下执行 `npm ci`。
2. 设置 `CENTER_ORIGIN` 为现有 HTTPS 登录服务、`CENTER_CERT` 为其受信任公开证书路径；运行 `sh start-preview.sh`。
3. 打开启动脚本指定的本机端口，使用现有账号。工作数据新建在本机运行目录；预览不连接用友保存接口。
4. 商品索引、税务历史、供应商配置、OCR 和商城授权由部署者另行配置。仓库不带真实原单、行情、账号库或任何密钥；默认不会得到真实模型或行情结果。

## 前端基线与构建边界

`web/assets/index-integrated.js` 基于现有部署包做局部集成，保留既有录单和发票页面。`order-integration.jsx` 是新增连续处理组件，`npm ci && npm run build:integration-ui` 可重建该组件。当前交付没有与现网部署包完全对应的完整原始 React 工程；不要从历史工程重建后覆盖本包。完整前端源码接续仍是后续维护缺口。

## 数据边界

所有价格为业务核对用参考；原价、未查询、空价、冲突及待核状态完整保留。报价原行重复接入不新增、不覆盖已有编辑。测试及样例未包含在此公共包。未完成中心机发布、员工验收、真实用友保存及真实行情全流程验证。

## 首版范围

这是 2026-09-22 的公开源码与现有编译界面快照，不是已完成客户验收的部署包。保留已有账号服务接入方式，没有演示账号、默认密码或供应商假响应。公开副本中的客户名称/默认目录标识已通用化；“示例客户”只是规则选项，不代表真实客户资料。

基础依赖覆盖表格工作流。图片OCR另需部署者安装并验证OCR运行依赖；`requirements-runtime.txt` 是原运行环境的版本快照，不承诺可跨平台原样安装。本次没有重新验证图片OCR、真实行情、模型调用、用友保存或员工登录。

不提供完整前端工程重建承诺；只可重建新增连续处理组件。第三方依赖许可见 `third-party-licenses/` 及编译包保留的声明；这些声明不等于为本项目指定新的开源许可证。
