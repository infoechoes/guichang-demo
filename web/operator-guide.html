首次在自己的电脑上使用

  1. 连接公司与贵昌服务器相同的内网。只需 Windows 电脑和浏览器，无需安装 Codex、Python 或用友客户端，也不需要用友账号和接口密钥。
  2. 从管理员取得“贵昌多人版-操作员试用.zip”和分配给你的个人账号。解压整个文件夹，双击 INSTALL-CERT.cmd，按照提示安装公开试用证书。已经安装过且没有证书告警的电脑无需重复安装。
  3. 打开 /，输入管理员分配的本程序账号和密码。不要填写用友 App Key / Secret。可将页面加入收藏夹。
  4. 登录后先检查默认配置中的客户、组织、业务员和知识库。按公司要求使用个人密码；可在顶部“修改密码”修改。

证书与访问地址由部署者提供。出现证书告警、地址无法打开或证书到期，请联系管理员处理，不要跳过告警继续录单。公司域名正式启用后，以管理员通知的新地址为准。

每次录单的流程

  1. 导入需求：在首页选择“图片”或“客户 Excel”。图片识别后核对商品编号、小数点、数量、单位、金额和备注中的配送地点。
  2. 选择配置：确认当前订单的客户和知识库；默认单据日期是今天，希望到货日期是明天，按实际业务修改。
  3. 匹配商品：点击“批量查询并更新默认价”。系统先匹配知识库，未找到候选再查用友。多个候选请核对规格后选择；未就绪商品可导出，已就绪商品可拆为独立子批次。
  4. 补充并保存草稿：按底部提示补充信息；单位不一致时，在报错旁点击“单位换算”，确认包装比例。离开前点“保存草稿”。草稿不会创建用友订单。
  5. 预览并确认：核对整单商品、数量、单价、金额和配送科室。预览后再明确点击“保存到用友”；保存成功后，如业务需要，再单独核对并提交。

上传或替换共享知识库

点击顶部“共享知识库”，上传最大 10MB 的 .xls / .xlsx。可选择最多 20 张工作表，合计最多 10000 行；逐表核对表头、商品编码、名称、规格、单位、价格和折扣。价格按实际表格口径处理，不统一打95折。

上传同名文件并检查后，可选择新建知识库或替换已有同名库；有多个同名库时须选定目标。确认替换后，全员可选择新版本，原文件和旧订单版本保留。已有订单或配置引用旧库时不会自动改价，可在知识库选择处明确“改用新版”；需要长期使用时再保存默认配置。整理过程中可手动保存个人草稿，恢复后重新检查再发布。

遇到问题时

情况处理方式
批量查询限流等待界面倒计时结束，点“手动继续未完成项”。不要连续重复查询。
登录过期在原页面用原账号重新登录可继续内存中的编辑；刷新或关页前仍需手动保存草稿。
保存／提交结果不明点“核查已有保存／提交结果”。只读核查原单，不重发订单。仍不能确定时联系管理员，勿复制新批次再次录入。
忘记密码联系管理员重置本程序密码；重置后所有设备需重新登录。
其他问题点顶部“复制问题信息”，把版本、问题编号和操作步骤交给管理员。不要发送密码或接口密钥。
